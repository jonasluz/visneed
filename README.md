# VisNeed

**VisNeed: Interactive Platform for Editing and Visualizing Generic and Flexible Decision Trees**

VisNeed is an interactive and user-friendly desktop app designed to simplify the creation, visualization, and editing of decision trees. Built as a complementary tool to the NEED decision tree editor (Barbosa & Rodrigues, 2025), VisNeed aims to make decision modeling more accessible to users, while also offering powerful features for researchers and developers.

---

## 🚀 Features

- 🎨 **Visual Editor** – Intuitive tree creation and editing  
- 🔍 **Tree Visualization** – Real-time rendering of decision trees in a dynamic layout  
- 💾 **Import/Export** – Support for importing and exporting trees in standardized formats   
- 🔧 **Flexible Integration** – Compatible with game engines and computational platforms  

---

## 📚 Background

The project extends the functionality of NEED (Barbosa & Rodrigues, 2025), a formal decision tree editor, by providing a more accessible and interactive experience. While NEED focuses on precise tree definition and export, VisNeed focuses on usability, accessibility, and adaptability.
